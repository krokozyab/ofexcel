# Надстройка-зонд (фаза 0)

Временная надстройка для проверок фазы 0, которые нельзя сделать без Excel (`docs/PHASE0_REPORT.md` §7).
После закрытия фазы 0 удаляется вместе с маршрутом `/v1/probe/rows` (`src/server/routes_probe.cpp`).

Что проверяет:

| Кнопка | Вопрос |
|---|---|
| 1 | Версии Office и наборов API, origin страницы, разрешение Local Network Access |
| 2 | Доходит ли `fetch` из WebView до `http://127.0.0.1:47321` и `http://localhost:47321`, проходит ли CORS preflight |
| 3a–3d | Сквозная запись в Excel Table: демон → JSON → Office.js, по этапам, на 10 тыс., 100 тыс. и 500 тыс. строк |
| 3c | A5: самая большая порция, которую принимает одна запись |
| 4 | A8: `Table.resize`, сохранение стиля, вычисляемой колонки и форматирования при обновлении |
| 5 | A6: становятся ли строки `=…`, `+…`, `-…`, `@…` формулами при формате `@` и без него |
| 6 | Система дат книги (1900 или 1904) |
| 7 | A7: как в пользовательские функции приходят пустые ячейки, пропущенные аргументы и `""`; работает ли регистрация функции после `await` |
| 8a–8c | Проверка 9: когда Excel перечитывает `functions.json` |

## Один раз
```sh
npx office-addin-dev-certs install     # сертификат для https://localhost, спросит пароль
mkdir -p ~/Library/Containers/com.microsoft.Excel/Data/Documents/wef
cp tools/addin-probe/manifest-dev.xml ~/Library/Containers/com.microsoft.Excel/Data/Documents/wef/qexcel-probe.xml
```

## Запуск
```sh
FUSION_ENDPOINT=https://<инстанс>.fa.ocs.oraclecloud.com \
FUSION_REPORT_PATH=/Custom/CloudSQL/RP_ARB.xdo \
tools/addin-probe/start.sh
```
При первом запуске скрипт загружает 500 тыс. строк `AP_INVOICE_LINES_ALL` в `state/qexcel_probe.duckdb`: нужен вход через SSO, загрузка идёт около двух минут. Затем он поднимает демон с маршрутом зонда и HTTPS-сервер разработки.

В Excel для Mac: **Вставка → Надстройки → Мои надстройки** → в разделе надстроек разработчика выбрать **QExcel probe** → на вкладке «Главная» нажать **Probe**.

Отчёт каждой сессии сохраняется в `tools/addin-probe/reports/<сессия>.json` после каждого эксперимента.

## Проверка 9 (кэш метаданных)
1. **8a** — сервер начинает отдавать вариант метаданных 2 с функцией `PROBE.NEW`.
2. Закрыть панель и открыть снова → **8b**.
3. Полностью закрыть Excel, открыть, открыть панель → **8b**.
4. **8c** — вернуть вариант 1.

По отчёту видно, после какого шага `=PROBE.NEW()` перестала давать `#NAME?`. Время запуска среды выполнения (`runtimeStartedAt`) показывает, перезапускалась ли она.
